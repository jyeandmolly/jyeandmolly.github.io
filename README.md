# Jye & Molly — wedding website

- **content.js** — all the words, times, links and the photo list. This is the file you edit.
- **photos/** — put image files here, then list them in content.js.
- **style.css** — colours and fonts are at the top if you want to change the look.
- **index.html** — builds the page. You shouldn't need to touch it.

To edit on GitHub: open a file, click the pencil icon, make your change, then "Commit changes". The live site updates within a minute or two.

Tip: resize photos to about 2000px wide before uploading so the site loads quickly.
